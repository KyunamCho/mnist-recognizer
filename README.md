# MNIST 손글씨 숫자 인식기

외부 라이브러리 없이 HTML, CSS, JavaScript로 동작하는 브라우저 기반 MNIST MLP 학습·예측 데모입니다.

## 실행

저장소 루트에서 Python 웹 서버를 실행하고 브라우저로 접속합니다.

```bash
python3 -m http.server 3000
```

`http://localhost:3000`을 열고 **mnist_784.tab 불러오기**를 누릅니다. `fetch`로 같은 폴더의 데이터 파일을 불러오므로 `file://`이 아닌 웹 서버를 통해 실행해야 합니다.

## 사용

1. 기본 MNIST 데이터 또는 호환되는 `.tab` 파일을 불러옵니다.
2. 에포크 수와 학습률을 설정하고 학습을 시작합니다.
3. 데이터 미리보기, 학습 그래프, 검증 혼동행렬과 오분류를 확인합니다.
4. 테스트 탭에서 손글씨를 그리거나 숫자 이미지를 올려 예측합니다.

학습은 784→128→64→10 MLP를 사용합니다. 데이터는 시드가 고정된 80:20 비율로 나누며, 학습과 데이터 파싱은 Web Worker에서 수행해 화면 조작이 계속 가능하도록 했습니다.
